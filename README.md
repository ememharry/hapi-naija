# 🇳🇬 Hapi Naija

**Built for Nigerians. Powered by Citizens. Independent of Government.**

Hapi Naija is an independently initiated, non-partisan civic-tech initiative led by **Emem Harry Etukudo**. It aims to help Nigerians share experiences with public services, expose service inequalities, and support evidence-informed improvements. It is **not government-owned or government-operated**.

## Current status — v0.1 prototype

**The repository is being prepared for its first software release; the application source is not published here yet.**

[View the working frontend demonstration](https://hapi-naija-b3gv5i.v2.appdeploy.ai/).

The demo supports local-only feedback, ratings, browser-local reference tracking and illustrative insights. There is no central backend, API, government integration or representative national dataset. Do not submit personal or sensitive information.

## Development roadmap

1. **Prototype verification** — publish audited frontend source, reproducible build, and clear demo-data warnings.
2. **Accessible participation** — low-bandwidth design, multilingual accessibility, rural and assisted feedback methods.
3. **Privacy-first backend** — documented APIs, secure access and moderation, with synthetic developer data.
4. **Trustworthy analysis** — bias reporting, sampling methodology, equity monitoring, and honest limitations.
5. **Community governance** — contribution guidelines, independent oversight, and transparent release processes.
